# KOS — Knowledge OS

Base frontend inspired directly by the original KOS/Notion workspace.

## Direction of this version
- Notion-like workspace navigation
- Databases are the primary interface
- Table-first views with simple Gallery option
- Domains → Lessons → Questions → Vaults remain the core structure
- Properties, filters, views and "New page" are visually represented like a database workspace
- Question remains the central learning unit
- Vault follows the user's original structure
- Progress remains visible across the learning stages
- Crono, Sessions, Reviews and KOS AI remain available without overwhelming the database experience

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

This is still a frontend product base with mock data. Backend, authentication, persistence and real AI integration should be added after the information architecture is approved.
